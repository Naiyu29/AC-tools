# AC 工具集 輸入／交換格式

本文件是三支工具**實際讀取**的格式（以 `docs/shared/*-math.js` 的解析程式為準，單元測試 `tests/unit/` 保證一致）。
收方 skill（shoufang-survey）匯出 AC TOOL 輸入檔時，以本文件為規格。

單位：里程／樁號 m、支距 m、高程 m。小數位不限，建議高程 3 位。

---

## 1. 斷面分析（`AC-斷面分析/`）

### 1.1 文字格式（貼入「原地面／刨除後／舖築後」三個輸入框）

每行一個里程（斷面）：

```
里程  高程1 高程2 … 高程k  支距1 支距2 … 支距k
```

- **高程在前、支距在後**，同一行內數量相等（k 點）。
- 支距：中心線（新路心）＝ 0，**左側負、右側正**。程式靠「支距區含 0」自動判斷 k；若整排都沒有 0 點，則以數值個數的一半切分（前半高程、後半支距）。
- 支距不必排序，程式會依支距由小到大排序。
- 分隔：空格、Tab、全形空格、逗號（半形／全形）皆可；全形數字會自動轉半形。
- 第一個欄位不是數字的行（標題）靜默略過；數值不足 3 個或無法切分的行會列在警告區，不中斷。
- 三個輸入框的**里程要能對得上**（同一里程才會互相比較）；某層缺某里程時，該里程只做有資料的比較。
- 「原地面」可留空，只做「刨除後 → 舖築後」。

範例（5 點：新路邊 −4.5、舊路邊 −2.0、新路心 0、+1.5、人行道 +4.5）：

```
0    10.052 10.071 10.083 10.079 10.060   -4.5 -2.0 0 1.5 4.5
20   10.105 10.122 10.131 10.128 10.110   -4.5 -2.0 0 1.5 4.5
```

### 1.2 JSON 匯入檔（「匯入資料」按鈕）

```json
{
  "n1": "原地面",  "d1": "<1.1 格式的多行文字>",
  "n2": "刨除後",  "d2": "<同上>",
  "n3": "舖築後",  "d3": "<同上，可為空字串>",
  "c":  "-4.5 -2 0 1.5 4.5"
}
```

`c` 是「刨鋪厚度計算 → 指定支距」預設值。`n*` 空白時用頁面預設名稱。

### 1.3 送到縱坡的橋接資料（程式間用，使用者不必手寫）

localStorage 鍵 `actool_bridge_zongpo`：

```json
{ "stations": [0, 20, 40], "elevations": [10.083, 10.131, 10.178], "offset": 0, "layer": "刨除後", "from": 0, "to": 40 }
```

## 2. 縱坡（`AC-縱坡/`）

每行「樁號 高程」，或只填高程一欄（自動補樁號 0, 10, 20…）：

```
0   10.083
20  10.131
40  10.178
```

- 任一行有兩個以上數字即視為「樁號 高程」模式；程式依樁號排序。
- 高程通常取「刨除後新路心」（支距 0）。

---

## 3. 地形測量 DTM（`AC-地形測量/`）

每行「點號 北(N) 東(E) 高程(Z)」（預設 NEZ；可切換 XYZ＝東北高）：

```
1  2705664.491  186194.696  12.672
```

對應收方主檔「刨除後-全測站」工作表的 `點號、N、E、Z` 欄。

CAD 中心線：貼 AutoCAD 對 Polyline 下 `LIST` 的完整輸出（含「在點 X= Y=」「凸度」「中心點」「半徑」行）。

## 4. 收方 Excel → AC TOOL：`tools/shoufang2actool.py`

收方主檔的「原始資料」工作表（見 shoufang-survey skill 的 workbook-format.md）**只有測點名稱、沒有支距**，
所以要多給一張「測點名稱 → 支距」對照表才能轉成斷面分析格式。

```bash
# 列出工作表與自動偵測到的欄位
python3 tools/shoufang2actool.py 20260721_瓊林段_刨除後收方.xlsx --sheet 刨除後原始資料-水準儀 --inspect

# 轉換：輸出 斷面分析 txt、JSON 匯入檔、縱坡 txt
python3 tools/shoufang2actool.py 20260721_瓊林段_刨除後收方.xlsx \
    --sheet 刨除後原始資料-水準儀 \
    --offsets tools/offsets.example.json \
    --layer 刨除後 \
    --out out/瓊林段_刨除後
```

產出：

| 檔案 | 用途 |
|------|------|
| `<out>.斷面.txt` | 貼入斷面分析對應層別的輸入框 |
| `<out>.import.json` | 斷面分析「匯入資料」（`--layer` 決定放在 d1/d2/d3） |
| `<out>.縱坡.txt` | 貼入縱坡（新路心高程） |
| `<out>.report.txt` | 轉換摘要：各里程點數、重複觀測處理、缺支距的測點 |

多階段合併：對原地面／刨除後／舖築後各跑一次，再用 `--merge a.import.json b.import.json c.import.json --out 合併` 合成一個三層 JSON。

### 對照表 `offsets.json`

```json
{
  "新路心": 0,
  "+1.5": 1.5,
  "舊路邊": -2.0,
  "新路邊": -4.5,
  "人行道": 4.5,
  "公車彎": -6.0
}
```

數值為**支距（m），左負右正**；每個工區第一次使用時向現場確認。沒有對照到的測點會跳過並寫進 report。

### 高程計算

轉換器**不讀 Excel 公式快取**，一律重算：`點高程 = 測站高程 + 後視讀數 − 讀數`，與 skill 的建表規則一致；讀數空白的點略過。

### 重複觀測（頁與頁、測站與測站交界）

同一里程出現在兩組測站設置時，預設取**平均**（`--dup mean`），可改 `--dup first`／`--dup last`；差值 > 5 mm 會在 report 標記，與 skill 的檢核門檻一致。
