# AC TOOL 輸入檔格式

**狀態:已定義(2026-10-08),規格來源 AC-tools repo `docs/FORMATS.md`,轉換器 `tools/shoufang2actool.py`。**

AC TOOL = 使用者的「AC 工具集」(GitHub Pages 靜態站,repo `naiyu29/AC-tools`),三支工具:斷面分析、縱坡、地形測量。收方成果主要餵給**斷面分析**。

## 斷面分析 文字格式(每行一個里程)

```
里程  高程1 … 高程k  支距1 … 支距k
```

- 高程在前、支距在後,同一行點數相等;支距以新路心為 0,**左負右正**。
- 分隔用空格;全形、逗號、Tab 程式都能吃,但輸出一律半形空格。
- 三層(原地面/刨除後/舖築後)各貼一個輸入框,里程要對得上。
- 另有 JSON 匯入檔:`{"n1","d1","n2","d2","n3","d3","c"}`,n=層名稱、d=上面的多行文字、c=指定支距預設值。

範例:
```
0  12.760 12.810 12.860 12.840 12.780  -4.5 -2 0 1.5 4.5
20 12.800 12.850 12.900 12.880 12.820  -4.5 -2 0 1.5 4.5
```

## 縱坡 文字格式

每行「樁號 高程」,取新路心(支距 0)高程。

## 地形測量 文字格式

每行「點號 N E Z」,對應主檔「刨除後-全測站」的點號、N、E、Z 欄。

## 匯出步驟(建完 Excel 後)

1. **取得測點→支距對照表**。原始資料工作表只有測點名稱(公車彎、新路邊、舊路邊、新路心、+1.5、人行道、加測點…),沒有支距。
   首次處理某工區時向使用者確認每個測點的支距(m,左負右正),存成 `offsets.json`;之後同工區沿用。
   瓊林段預設(待使用者確認):新路心 0、+1.5 → 1.5、舊路邊 −2.0、新路邊 −4.5、人行道 4.5、公車彎 −6.0。
2. 執行轉換(repo 內):
   ```bash
   python3 tools/shoufang2actool.py <活頁簿>.xlsx --sheet "<原始資料工作表>" \
       --offsets offsets.json --layer 刨除後 --out <YYYYMMDD_工區_階段>
   ```
   產出 `.斷面.txt`(貼輸入框)、`.import.json`(匯入按鈕)、`.縱坡.txt`、`.report.txt`。
   多階段用 `--merge a.import.json b.import.json --out 合併` 合成三層一檔。
   沒有 repo 時,依上面格式直接產檔:高程 = 測站高程 + 後視讀數 − 讀數,3 位小數;交界重複觀測取平均並在報告列出差值。
3. 交付時一併回報 report 內容:各里程點數、重複觀測差值 >5mm 者、沒有支距對照而略過的測點。

## 注意

- 轉換器不讀 Excel 公式快取,一律重算高程,所以謄打完不必先在 Excel 重算。
- 標題列 `="+1.5"` 這種公式字串會自動還原成 `+1.5`。
- 斷面分析對里程順序沒有要求,但縱坡會依樁號排序。
