# AC 工具集 · 計算檢查與自動測試

這個資料夾不會發佈到網站（GitHub Pages 只發佈 `docs/`）。

## 2026-10-10 檢查結果

用可以手算答案的資料，實際在瀏覽器裡操作三支工具，對照畫面上的數字。

| 工具 | 問題 | 影響 | 狀態 |
|---|---|---|---|
| 斷面分析 | 某一站只有部分斷面（例如舖築後隔站測），那一站面積被當成 0 | 前後兩段的量直接少一半，畫面沒有提示 | 已修：缺斷面的站不列入、以相鄰站連算，並顯示警告 |
| 斷面分析 | 同一支距有兩個高程（側溝、緣石立面）被拉成斜線 | 該段面積多算（測試案例多 8%） | 已修 |
| 斷面分析、縱坡 | 樁號寫成 `0+120`、`1K+020` 會被當成標題行丟掉 | 整份資料或部分行消失 | 已修：自動換算成公尺 |
| 斷面分析、縱坡 | 雲端（Firebase）用靜態載入 | 工地網路連不到 Google 時整支工具沒反應，連計算都不行 | 已修：雲端改為需要時才載入，連不上只影響存檔與分享 |
| 地形測量 | 只認空白分隔 | 全站儀／RTK 匯出的 CSV（逗號分隔）讀進來是 0 點 | 已修：空白、Tab、逗號都可以 |
| 地形測量 | 樁號顯示先拆 K 再四捨五入 | 1999.999 顯示成 `1K+1000.00` | 已修 |
| 斷面分析 | Chart.js 沒鎖版本 | Chart.js 出新大版本那天圖表外掛可能不相容 | 已鎖定 4.5.1 |
| 雲端規則 | 存檔的「修改」不用登入 | 任何人都能把別人的存檔內容蓋掉 | `firestore.rules` 已改成要登入；**要另外發佈才生效** |

確認正確、沒有改的：刨除／舖築面積的梯形與交叉點公式、平均斷面法、縱坡平順化（厚度上下限與平均）、地形 IDW 內插、NEZ 座標對應、中心線左右判斷。

### 「推估平均厚度」怎麼算

各站的面積 ÷ 該斷面的總寬度，再取各站平均。斷面量到路肩、側溝等沒有刨舖的範圍時，平均厚度會比實際刨舖範圍的厚度小（面積與總量不受影響）。

## 發佈雲端規則

`firestore.rules` 的修改要發佈到 Firebase 才會生效。最簡單的方式：

1. 打開 Firebase 主控台 → 專案 `ac-tool-529aa` → Firestore Database → 規則。
2. 把 `firestore.rules` 的內容整份貼上，按「發布」。

發佈後，沒登入的人仍可瀏覽紀錄與開分享連結，但儲存、改名需要先用 Google 登入。

## 跑測試

```
cd tests
npm install
npx playwright install chromium
npm test
```

測試不連網路：Chart.js 與外掛從 npm 套件提供，Google 雲端用假的或直接擋掉。每一組資料的正確答案寫在 `tools.test.js` 的註解裡。
